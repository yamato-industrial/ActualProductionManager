# コンテナ定義書

## システム概要

### システム名

ActualProductionManager

### コンテナ名

actualproductionmanager-webapp

### 用途

生産実績管理システム用のマスタ管理Webアプリケーション。

主な機能

- 段取り時間マスタ管理（setup_times）
- マスタ参照
- 設定管理

## 実行環境

### ホスト環境

| 項目         | 内容              |
| ------------ | ----------------- |
| 機器         | QNAP TS-453D      |
| コンテナ管理 | Container Station |
| ランタイム   | runc              |
| ネットワーク | bridge            |

### コンテナ環境

| 項目             | 内容           |
| ---------------- | -------------- |
| OS               | Ubuntu 24.04   |
| Webサーバー      | Nginx          |
| アプリケーション | ASP.NET Core 8 |
| 実行ユーザー     | root           |

## ボリューム定義

| ボリューム名                       | コンテナパス | 用途                 |
| ---------------------------------- | ------------ | -------------------- |
| actualproductionmanager_entrypoint | /entrypoint  | 起動スクリプト       |
| actualproductionmanager_nginx      | /etc/nginx   | nginx設定            |
| actualproductionmanager_app        | /var/app     | アプリケーション配置 |

## docker-compose

```yaml
version: "3"

services:
  webapp:
    image: ubuntu:24.04
    container_name: actualproductionmanager-webapp

    ports:
      - 49153:80

    volumes:
      - entrypoint:/entrypoint
      - nginx:/etc/nginx
      - app:/var/app

    network_mode: bridge

    entrypoint: >
      /bin/bash -c '
      chmod +x /entrypoint/docker-entrypoint.sh &&
      /entrypoint/docker-entrypoint.sh
      '

    tty: true

volumes:
  entrypoint:
  app:
  nginx:
```

## エントリポイント定義

### ファイル

/entrypoint/docker-entrypoint.sh

### 処理内容

1. Ubuntuパッケージ更新
2. .NET SDK 8.0インストール
3. Nginxインストール
4. Nginx起動
5. ASP.NETアプリ起動

実装方式は既存の InternalInformationApi コンテナと同一とする。 [[yamato3111...epoint.com\]](https://yamato3111-my.sharepoint.com/personal/h_yoshizawa_yamato3111_onmicrosoft_com/Documents/Microsoft Copilot Chat ファイル/docker-entrypoint.sh)
